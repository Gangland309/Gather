# Gather v0.9.18 — copper and teal

Light uses warm ivory and cream panels, copper-orange buttons and deep-teal accents. Dark uses graphite panels, soft copper buttons and brighter teal accents. Both modes use the new palette; toggling Dark off no longer returns to the original purple/lime colors. Current light/dark preference remains selectable in Settings.

The connected Gather logo, default G profile picture, app icon, splash icon and favicon are recolored to copper and teal. Find Your People remains beside the top logo. Existing layout, sharper edges and functionality are preserved.

Includes v0.9.17 live host-camera thumbnails, the live/mixed/Sparks feeds, link previews, hover/autoplay behavior, green-screen background upload and persistent login. This release does not add unfinished camera face effects, advanced video editing, SMS or recommendation algorithms.

Deploy both server and client using INSTALL-THIS-UPDATE.md. TypeScript, lint, all platform exports and ZIP integrity are verified before packaging. This is a cumulative source/bundle update, not signed app-store installers. Phone, visual layout and real-camera/live preview validation remain pending.

Logo artwork edited with the built-in image editor. Edit brief: preserve existing letterforms/G emblem and framing, replace purple/blue with copper, green/silver with teal, and use an ivory backdrop. Project assets: mobile/assets/gather-logo.png and mobile/assets/gather-default-avatar.png.
