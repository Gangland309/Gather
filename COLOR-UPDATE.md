# Gather 0.7.1 — Purple and Lime

The interface now follows the existing Gather wordmark: deep purple primary actions, lime online indicators/navigation details/feed accents, cool white cards and neutral backgrounds. Dark mode uses near-black purple surfaces, readable lavender actions and bright lime accents. Sharp Inter typography and existing features remain included.

| Element | Light | Dark |
| --- | --- | --- |
| Background | #f7f7fa | #100d17 |
| Surface | #ffffff | #1b1625 |
| Action | #5800c7 | #b99aff |
| Lime detail | #92d51f | #a2e62a |

Use INSTALL-THIS-UPDATE.md for Render installation. This update replaces the copper palette. Native signed apps need a new build. Physical device visual testing has not been performed.
