# Gather 0.6.1 — Ivory, Charcoal & Copper

The interface uses warm ivory backgrounds and copper actions in light mode, with charcoal surfaces and peach-copper actions in dark mode. Navigation, buttons, cards, messages, live controls, feed overlays, and profile-picture borders follow the palette. The purple-and-lime wordmark and G avatar remain unchanged.

| Element | Light mode | Dark mode |
| --- | --- | --- |
| Background | #f5f0e8 | #181412 |
| Cards | #fffcf7 | #251f1b |
| Main text | #29221f | #f7efe4 |
| Secondary text | #73655d | #c6b5a7 |
| Action accent | #91452d | #e5a37b |
| Selection tint | #eee0d0 | #382a22 |

Install this cumulative ZIP the same way: back up data, extract, copy the gather folder’s contents into the repository while keeping .env and persistent data, commit/push, wait for Render Live, and refresh. On Windows browsers, Ctrl+F5 can refresh cached assets after deployment. Native signed apps need a new build to display the changes.

Discord and contact setup remains in DISCORD-SETUP.md. All earlier functionality is included. Color changes do not configure LiveKit, Discord credentials, payments, or suppliers. TypeScript/lint and web/iOS/Android exports were checked; no real-device visual test was performed.
