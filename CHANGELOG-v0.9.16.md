# Gather v0.9.16

New dark palette: true black background, charcoal panels, icy blue accents, silver-white text, cool gray secondary text and clearer slate borders. Selected states and feed overlay accents follow the same palette. The existing logo is recolored icy blue and silver on black, and the top bar adds “Find Your People” beside it. Existing light/system theme preferences remain available; choose Settings → Appearance → Dark to see this palette if your saved preference is Light.

Layout, spacing, sharp edges, feeds and functionality remain as in v0.9.15. Includes all earlier live feeds, autoplay, link previews, green-screen uploads and persistent-login changes. This is a color-only release with a version bump.

Deploy this cumulative update using INSTALL-THIS-UPDATE.md. Code checks and the web export are verified before packaging. Real-phone and visual layout validation remain pending. No deployment has been performed.

The logo was recolored using the built-in image editor. Edit brief: preserve connected GATHER letterforms and framing; recolor purple to icy blue, lime to silver, background emblem to blue-gray, and white background to black. Updated project asset: mobile/assets/gather-logo.png.

Contrast checks: main text/panel 16.27:1; secondary text/panel 9.52:1; button text/accent 11.93:1; accent/selected panel 8.58:1. These checks cover the new palette, not every screen or image overlay.
