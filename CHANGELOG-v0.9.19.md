# Gather v0.9.19 — your Gatherings

Gatherings opens to Your Gatherings: groups you own or have approved membership in. Discover Gatherings shows groups you have not joined, with pending applications marked Request pending. Search works within the selected section. Joining, approval and leaving update the appropriate section when the list reloads. Server filtering occurs before the result limit and retains block/ban restrictions. Existing audience/group-picker endpoints are unchanged.

Two explicit segment buttons replace the old Show all/My toggle. Fan Clubs use the same segmented presentation. Pending membership does not count as joined. Latest list requests win when switching sections, so earlier responses cannot overwrite the selected catalog.

Includes all previous features and the copper/teal Light and Dark palette, updated logo and default G avatar. Deploy both server and client using INSTALL-THIS-UPDATE.md. 120 tests, TypeScript, lint and all platform exports are checked before packaging. Phone/visual validation remains pending.
