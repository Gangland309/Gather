# Settings, direct calls, combined logs and sound · 0.8.4

Includes all earlier changes. Settings is a main navigation option. Call settings persist on the server: who may call (Friends only by default, Any verified Gather user, Nobody), call/missed-call Activity notifications, and unanswered timeout (30, 60 or 120 seconds). Changes affect new calls. Appearance and links to account privacy/settings are included.

Calls start directly from a profile or message thread's Call button. Call membership is authorized at creation by the recipient's calling policy. The recipient joins directly using an incoming-call banner; no separate request approval is required. Joining still takes a tap. Nobody's microphone/camera starts automatically. Calls are removed from the request-approval inbox; other requests retain Accept/Deny.

Connect → Messages & Calls combines the message conversation log and individual call log entries chronologically. Filters: All, Messages, Calls, Missed calls. Open conversation, Join call and Call again actions are available. Incoming banners refresh every five seconds while Gather is open. Message conversation entries use the latest message time/preview. Call entries keep each call's direction/status/duration. Incoming message requests stay in Requests until approved.

Browser sound settings are available in Settings and in live call/voice-party sessions: microphone and speaker selection, 0–100% speaker volume, echo cancellation, noise suppression and automatic microphone level. Preferences are saved per browser, not synchronized between devices. Enabling the microphone grants access and lets device names become available; refresh devices afterwards. Browser processing support varies, speaker switching can be unavailable, and unsupported output selection shows a useful message. Processing changes apply to the currently enabled microphone; muted microphones use the settings when enabled. Microphones/cameras stay off initially. Native apps use the existing browser studio; adjust the sound controls there. Device sound volume remains controlled by the operating system. No embedded native RTC/audio processing, audio quality benchmark, real-device/provider test or OS background ringing was completed.

Existing private calls without a call-history record cannot be resumed after the update. End any current sessions before deploying. Follow INSTALL-THIS-UPDATE.md; preserve the existing database and uploads.
