# Working invitation links and external sharing · 0.8.7

Includes all prior changes: marketplace posts, member wallets, owner GC issuance and 45 themed gift previews.

Invite → Create invitation link generates a server-issued signup URL using PUBLIC_ORIGIN (or RENDER_EXTERNAL_URL; localhost:8081 for local development). It is not just a homepage link. The invitation field is prefilled and checked when opened. Links expire after seven days and admit one signup, with verification and atomic consumption enforced by the server. Invalid, expired and used codes are rejected. Revocation is restricted to the issuer. Verified members may generate five links per rolling 24 hours. Verified owner admins can generate more. Operators can set MEMBER_INVITES=false in Render to stop regular members issuing new invitations; owner issuance continues. INVITE_ONLY=true keeps signup invitation-gated. Valid codes supplied during open registration are also consumed once. Existing old invitations remain valid until their existing expiry.

Copy Link and Share controls use expo-clipboard and the native/browser share menu. Invite, profile and approved shop listing links can be shared. Post and Spark sharing rechecks the creator's sharing preference, respects the current canShare flag, and uses the configured Gather domain rather than a fixed domain. Public posts/profiles can use existing public views. Private posts keep their account/friend/Gathering permissions. Shop links open the shared listing after sign-in; shop browsing remains members-only. Browser sharing is used when available, otherwise the link is copied. Installed apps and platform support decide share targets. This is link sharing, not auto-uploading media into TikTok/Instagram or posting to connected accounts. Universal/app-store deep linking and native signed installers are not configured; HTTPS invite links work in the web app.

Testing covers generated URLs, public validity checks, successful signup, single-use replay rejection, issuer-only revocation, member quota and verified issuer access. Clipboard/share-menu behavior and links on real phones still need device testing. Nothing was deployed to Render here.

Install with INSTALL-THIS-UPDATE.md. ADMIN-GC-AND-GIFTS-UPDATE.md explains admin setup and GC issuance. Set ADMIN_EMAIL to your Gather login email in Render and verify the account before using the admin wallet panel. Payments, gift transactions and cash-out remain disabled.
