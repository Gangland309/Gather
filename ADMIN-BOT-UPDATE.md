# Gather 0.8.9 — Admin content bot

Open **Admin control panel** (the existing Moderation section) while signed in as admin. The **Gather content bot** appears first.

1. If the official page does not exist, press **Set up official Gather page**. This uses the existing official-page setup and follows it for current users.
2. Press **Generate 7 drafts** for welcome posts, community questions, feature tips and public Gathering spotlights.
3. Edit and **Save draft**, or **Discard draft**.
4. Press **Publish…**, review the public-post confirmation, then **Confirm public publish**. The post is authored by Gather, not your personal account.
5. Use **Refresh drafts** to load changes made elsewhere. Refreshing replaces local unsaved edits; save those first.

The same bot remains available on the official Gather page. Both locations share the same saved drafts. Publishing is protected against duplicate submissions. This version uses a rotating text library, without a paid AI API key. Automatic schedules, generated images/videos and autonomous moderation are not implemented.

Admin access: in Render set ADMIN_EMAIL to your Gather login email, deploy, verify that email, then sign out/in. Follow INSTALL-THIS-UPDATE.md to deploy this cumulative ZIP. The update includes the previous live-gifting features.
